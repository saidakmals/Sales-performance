# Pizza Sales Analytics Dashboard

An end-to-end Business Intelligence project built using Power BI and MySQL to analyze pizza sales performance and generate actionable business insights through interactive dashboards and reporting.

## Project Overview

This project focuses on transforming raw transactional sales data into a dynamic and interactive analytics dashboard. The dashboard provides insights into sales performance, customer ordering behavior, product trends, and operational KPIs using modern business intelligence tools and data visualization techniques.

The workflow included:

* Importing and cleaning raw sales data
* Transforming date and categorical fields using Power Query
* Writing SQL queries in MySQL for KPI validation and analysis
* Building interactive visualizations and dashboards in Power BI
* Creating DAX measures for performance tracking and calculations

## Key Features

### KPI Metrics

* Total Revenue
* Total Orders
* Total Pizzas Sold
* Average Order Value
* Average Pizzas per Order

### Sales Performance Analysis

* Monthly revenue trends
* Daily order distribution
* Sales analysis by pizza category
* Sales analysis by pizza size
* Top-performing pizzas by revenue and quantity sold

### Interactive Reporting

* Dynamic filtering and slicers
* Drill-down analysis
* Interactive dashboard navigation
* Time-based analysis and trend visualization
